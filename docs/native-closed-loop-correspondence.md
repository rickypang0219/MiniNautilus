# Closed-loop correspondence qualification

Created UTC: 2026-10-18T07:33:00Z. Frozen manifest: `comparisons/native-readiness/closed-loop-v1.json`.

This extends the existing interactive backtest path: `mininautilus sim --external-venue` keeps the same in-memory Rust Core/protocol but disables automatic PaperExchange replies. The Python cold-path depth matcher supplies explicit execution reports; it is never used for live execution. Existing candle/target backtests keep their original matching behavior. Python strategies still retain only their eight-bar SMA window.

The replay consumes public fast L2, public trades, available-at closed bars, public oracle observations, settled public fundingHistory, and a predeclared run timer. Recorded private fills, private funding, live intents and reported target answers are not simulation inputs. Own simulated fills change Core inventory, which determines later order quantities. The same 3/8 SMA is recomputed; a separate rational/list-based oracle checks actual accounting and signal parity. An explicit timer stops new strategy risk, cancels the model's own remainder and flattens its own inventory using the existing 0.1% outward whole-dollar collar. Operational flatten costs stay in both ledgers. This only covers individual flat-boundary segments, not continuous state across strategy restarts or PCA portfolio risk.

Arrival uses **960ms**, rounded from a separate 14-order calibration's median Core-input→first-execution interval of 960.5ms. This is a proxy, not an observed socket/venue arrival; it assumes zero local/exchange UTC offset. Raw hashes and all samples are retained in `closed-loop-calibration-v1.json`. Cancellation remains an uncalibrated 520ms assumption. No parameter is retuned on holdout. The historical user fee schedule was read again before freezing: taker 0.00045, maker 0.00015. Signed fees/funding truncate to 0.000001 USDC. Settlement funding uses simulated inventory at its effective time and an oracle available before settlement at most 2s old; missing oracle evidence makes net PnL unknown. Private actual funding is never copied to a different simulated inventory.

The matcher uses only depth already available at the modeled arrival, consumes a snapshot once, and advances passive queue estimates only using opposing public trades after arrival. Initial displayed same-price size is placed ahead. Cancellations, hidden priority, impact and same-millisecond book ambiguity remain limitations. Every passive/missing-depth simulated order and every actual order without a fully-filled acknowledgement stays visible and prevents a complete covered-class PASS. Adverse or unmatched decision/side groups remain in the quantity/order-count denominators. A common mistake is comparing only groups that both models filled; regression tests reject that approach.

Holdout is two separate 900-second Tokyo sessions, with a deliberately tightened **10s segment-age trigger** to collect distinct executions quickly. The production defaults remain 800 orders/30min and the hard ceiling 1,000. Repeated bounded warmups are not independent signal histories: report distinct bar times as well as execution counts. Each 15-minute run stops the experiment on lifecycle failure or quantitative FAIL; INCONCLUSIVE stays inconclusive. At least 100 actual and simulated orders, ≤5% lot and order-count differences, ≤2bps maximum grouped VWAP error, zero signal mismatch and independent ledger agreement within one cash quantum are required. These numbers do not promise equal actual/model PnL: record gross execution, fees, funding, inventory/mark and operational effects separately to attribute differences.

A failed or incomplete correspondence gate blocks the proposed 24h qualification. A short run cannot substitute for 24 elapsed hours. The existing retained-EBS takeover proof also does not substitute for upgrade/rollback, persistent human-stop, alert receipt or EBS/AZ disaster exercises. No mainnet execution is enabled by this work.
